1. Hypothesis Testing HIGHEST EXAM WEIGHT

What is it?

Hypothesis testing lets us make decisions about population parameters using sample data. We start with a null hypothesis (H₀: the status quo) and an alternative hypothesis (H₁: what we're trying to prove). We calculate a test statistic and compare it to a threshold to decide whether to reject H₀.

The 5-Step Framework (USE THIS EVERY TIME)

  1. State hypotheses: H₀ and H₁
  2. Choose significance level: α (usually 0.05 or 0.01)
  3. Compute the test statistic: z or t
  4. Find p-value OR compare to critical value
  5. Conclusion: Reject H₀ or Fail to reject H₀
⚠️ NEVER say "accept H₀" — always say "fail to reject H₀". This is a common point-deduction trap.

1a. Z-Test (σ known)

Z-TEST STATISTIC z = (x̄ − μ₀) / (σ / √n)

WHEN TO USE • Population standard deviation σ is KNOWN • n is large (≥ 30) OR population is normal
PRACTICE — Z-Test (from HW6 Q3, 15 points)

Problem: A sensor has known σ = 0.25 and reference mean μ₀ = 5. We take 10 measurements from a new sensor: {4.5, 5.2, 4.3, 4.5, 4.9, 5.5, 4.2, 5.1, 4.1, 4.5}. Is the new sensor significantly different?

Step 1 — Hypotheses: H₀: μ = 5, H₁: μ ≠ 5 (two-tailed)
Step 2 — Significance: α = 0.05
Step 3 — Sample mean: x̄ = (4.5+5.2+4.3+4.5+4.9+5.5+4.2+5.1+4.1+4.5)/10 = 46.8/10 = 4.68
Step 4 — Test statistic: z = (4.68 − 5) / (0.25/√10) = −0.32 / 0.07906 = −4.0477
Step 5 — p-value: p = 2 × P(Z < −4.0477) = 2 × 0.0000259 ≈ 0.0001 (two-tailed)
Conclusion: p ≪ 0.05, so REJECT H₀. The new sensor is significantly different.
PRACTICE — Z-Test (from HW6 Q4, 13 points)

Problem: Previous studies show average height μ₀ = 1.8m, σ = 0.3m. A sample of n=36 people has x̄ = 1.6839. Has the average height changed? (α = 0.01)

Hypotheses: H₀: μ = 1.8, H₁: μ ≠ 1.8
z = (1.6839 − 1.8) / (0.3/√36) = −0.1161 / 0.05 = −2.3222
Critical value at α=0.01 two-tailed: z₀.₀₀₅ = ±2.5758
|z| = 2.32 < 2.58, and p = 0.0202 > 0.01
Conclusion: FAIL TO REJECT H₀ at 1% level. Not enough evidence.

1b. One-Sample T-Test (σ unknown)

T-TEST STATISTIC t = (x̄ − μ₀) / (s / √n) where s = sample standard deviation = √[ Σ(xᵢ − x̄)² / (n−1) ] degrees of freedom: df = n − 1

WHEN TO USE • Population σ is UNKNOWN → use sample s instead • Typically small sample (n < 30), but works for any n • Use t-table with df = n − 1
PRACTICE — One-Sample T-Test (from HW6 Q1, 15 points)

Problem: Algorithm runtime data (n=15): {17.5, 16.3, 18.4, 14.9, 16, 16.5, 18.5, 15.9, 18, 18.5, 18.1, 15.3, 17.6, 17.7, 17.8}. Population mean μ₀ = 16.5. Is there a difference?

Hypotheses: H₀: μ = 16.5, H₁: μ ≠ 16.5 (two-tailed)
Sample stats: n = 15, x̄ = 17.1333, s = 1.2069
t = (17.1333 − 16.5) / (1.2069/√15) = 0.6333 / 0.3116 = 2.0323
df = 14, p-value (two-tailed) = 0.0615
Conclusion: p = 0.0615 > 0.05, so FAIL TO REJECT H₀. No significant difference.
PRACTICE — One-Sided T-Test (from HW6 Q5, 15 points)

Problem: Method 1 scores: {10,4,6,7,12,5,7,4,12,10,9,10,8,5,9}. Population (Method 2) mean = 8. Does Method 1 outperform?

Hypotheses: H₀: μ ≤ 8, H₁: μ > 8 (right-tailed)
n = 15, x̄ = 7.8667, s = 2.6957
t = (7.8667 − 8) / (2.6957/√15) = −0.1333/0.6961 = −0.1916

1c. Two-Sample (Welch) T-Test

TWO-SAMPLE T-TEST (Independent Groups) t = (x̄₁ − x̄₂) / √(s₁²/n₁ + s₂²/n₂) Welch df ≈ (s₁²/n₁ + s₂²/n₂)² / [ (s₁²/n₁)²/(n₁−1) + (s₂²/n₂)²/(n₂−1) ]

WHEN TO USE • Comparing means of TWO INDEPENDENT groups • σ₁ and σ₂ unknown (use sample variances)
PRACTICE — Two-Sample T-Test (from HW6 Q2, 20 points)

Problem: Body fat % — Men (n=13): {13.3,6,20,8,14,19,18,25,16,24,15,1,15}; Women (n=10): {22,16,21.7,21,30,26,12,23.2,28,23}. Significant difference?

Hypotheses: H₀: μ_men = μ_women, H₁: μ_men ≠ μ_women
Men: x̄₁ = 14.9462, s₁ = 6.8426
Women: x̄₂ = 22.29, s₂ = 5.3197
t = (14.9462 − 22.29) / √(6.8426²/13 + 5.3197²/10) = −7.3438 / 2.5363 = −2.8958
Welch df ≈ 20.99, p = 0.0086
Conclusion: p = 0.0086 < 0.05, REJECT H₀. Significant difference exists.

WHEN TO USE • Same subjects measured TWICE (before/after, test1/test2) • Data comes in PAIRS

1e. Type I & Type II Errors

H₀ is TRUEH₀ is FALSE
Reject H₀Type I Error (α)
False Positive		Correct! (Power = 1−β)
Fail to Reject H₀Correct!Type II Error (β)
False Negative

α (significance level): Probability of rejecting H₀ when it's actually true. You choose this (0.05, 0.01, etc.).

β: Probability of failing to reject H₀ when it's actually false.

Power = 1 − β: Probability of correctly rejecting a false H₀.

⚠️ Exam trap: "Type I = False Positive = rejecting a true H₀" and "Type II = False Negative = keeping a false H₀". Remember: Type I = 1st kind of mistake = being too eager to reject.

1f. Z-Test for Proportions

Z-TEST FOR PROPORTIONS z = (p̂ − p₀) / √(p₀(1 − p₀) / n) where p̂ = sample proportion, p₀ = hypothesized proportion

WHEN TO USE • Testing whether a population proportion equals a claimed value • n is large enough: np₀ ≥ 5 and n(1−p₀) ≥ 5
PRACTICE — Z-Test for Proportions (from Session 21 — Clinton Poll)

Problem: A politician claims 50% support. A poll of n=518 voters finds 45% support (p̂=0.45). At α=0.05, is the true proportion different from 50%?

Hypotheses: H₀: p = 0.5, H₁: p ≠ 0.5 (two-tailed)
z = (0.45 − 0.5) / √(0.5 × 0.5 / 518) = −0.05 / √(0.000483) = −0.05 / 0.02198 = −2.275
p-value (two-tailed): p = 2 × P(Z < −2.275) ≈ 2 × 0.0115 = 0.023
Conclusion: p = 0.023 < 0.05, so REJECT H₀. The true proportion significantly differs from 50%.

σ known? → Z-test

"Different from"? → Two-tailed test

2. Confidence Intervals / Interval Estimation HIGH

What is it?

Instead of estimating a parameter with a single number (point estimate), we give a range [θ̂_l, θ̂_h] that likely contains the true value. The confidence level (1−α) is the probability the interval captures the true parameter.

2a. Z-Interval (σ known, large n)

CONFIDENCE INTERVAL FOR MEAN (σ KNOWN) CI = [ x̄ − z_{α/2} · σ/√n , x̄ + z_{α/2} · σ/√n ] Margin of Error = z_{α/2} · σ/√n

2b. CI with Unknown σ — Three Approaches

APPROACH 1: UPPER BOUND (Conservative) If σ ≤ σ_max, use: CI = [ x̄ − z_{α/2} · σ_max/√n , x̄ + z_{α/2} · σ_max/√n ] (Wider interval but always valid) APPROACH 2: SAMPLE STANDARD DEVIATION (General) S = √[ Σ(xₖ − x̄)² / (n−1) ] CI = [ x̄ − z_{α/2} · S/√n , x̄ + z_{α/2} · S/√n ] (Requires large n for z; use t for small n) APPROACH 3: BERNOULLI SPECIAL CASE Conservative (upper bound σ_max = 0.5): CI = [ x̄ − z_{α/2}/(2√n) , x̄ + z_{α/2}/(2√n) ] Estimated variance: CI = [ x̄ − z_{α/2}·√(x̄(1−x̄)/n) , x̄ + z_{α/2}·√(x̄(1−x̄)/n) ]

2c. T-Interval (σ unknown, small n, normal population)

CONFIDENCE INTERVAL USING T-DISTRIBUTION CI = [ x̄ − t_{α/2, df} · s/√n , x̄ + t_{α/2, df} · s/√n ] df = n − 1 Use t-table instead of z-table
🔑 Common z_{α/2} values (MEMORIZE):
90% CI (α=0.10): z₀.₀₅ = 1.645
95% CI (α=0.05): z₀.₀₂₅ = 1.96
99% CI (α=0.01): z₀.₀₀₅ = 2.576
PRACTICE — Confidence Interval

Problem: A sample of n=50 light bulbs has mean lifetime x̄ = 1200 hours with known σ = 100 hours. Find the 95% confidence interval for the true mean lifetime.

Identify: σ known, n large → Z-interval
z_{α/2} = z₀.₀₂₅ = 1.96
Margin of error = 1.96 × 100/√50 = 1.96 × 14.14 = 27.72
CI = [1200 − 27.72, 1200 + 27.72] = [1172.28, 1227.72]
Interpretation: We are 95% confident the true mean lifetime is between 1172.28 and 1227.72 hours.
PRACTICE — Bernoulli CI

Problem: In a poll of n=400 voters, 220 support candidate A (x̄ = 220/400 = 0.55). Find 95% CI for the true proportion θ using (a) conservative method and (b) estimated variance.

(a) Conservative: CI = [0.55 − 1.96/(2√400), 0.55 + 1.96/(2√400)] = [0.55 − 0.049, 0.55 + 0.049] = [0.501, 0.599]
(b) Estimated: σ̂ = √(0.55×0.45/400) = √(0.000619) = 0.02487
CI = [0.55 − 1.96×0.02487, 0.55 + 1.96×0.02487] = [0.501, 0.599]
(In this case they're very close; the conservative method is wider in general.)

3. Information Theory HIGH

What is it?

Measures the amount of "surprise" or "uncertainty" in random variables. Entropy tells us how unpredictable a source is. Mutual information tells us how much knowing one variable tells us about another.

All Information Theory Formulas

SELF-INFORMATION (of a single event) I(x) = −log₂(P(x)) [in bits] I(x) = −ln(P(x)) [in nats] I(x) = −log₁₀(P(x)) [in Hartleys] ENTROPY (average uncertainty of X) H(X) = −Σ P(xᵢ) · log₂(P(xᵢ)) JOINT ENTROPY H(X,Y) = −Σ_x Σ_y P(x,y) · log₂(P(x,y)) CONDITIONAL ENTROPY H(X|Y) = −Σ_x Σ_y P(x,y) · log₂(P(x|y)) where P(x|y) = P(x,y) / P(y) MUTUAL INFORMATION I(X;Y) = Σ_x Σ_y P(x,y) · log₂[ P(x,y) / (P(x)·P(y)) ] SHORTCUT: I(X;Y) = H(X) + H(Y) − H(X,Y) ALSO: I(X;Y) = H(X) − H(X|Y) = H(Y) − H(Y|X) KL-DIVERGENCE (Relative Entropy) D(P ‖ Q) = Σ P(i) · log₂[ P(i) / Q(i) ] NOTE: D(P‖Q) ≠ D(Q‖P) (NOT symmetric!) NOTE: D(P‖Q) ≥ 0 always UNIT CONVERSIONS H_Hartleys = H_bits × log₁₀(2) = H_bits × 0.3010 H_nats = H_bits × ln(2) = H_bits × 0.6931
⚠️ Key properties: Entropy is MAXIMIZED when all outcomes are equally likely. For n equally likely outcomes: H = log₂(n). KL-Divergence is NOT symmetric.

Important Identities & Bounds (from Session 13–14)

Chain Rule: H(X,Y) = H(X) + H(Y|X) = H(Y) + H(X|Y)

Conditional Entropy Identity: H(X|Y) = H(X,Y) − H(Y)

Bounds on Joint Entropy: max(H(X), H(Y)) ≤ H(X,Y) ≤ H(X) + H(Y)

Left bound: joint can't have less uncertainty than either variable alone. Right bound: equality holds only when X and Y are independent.

Mutual Information: I(X;Y) ≥ 0 always. I(X;Y) = 0 ⟺ X and Y are independent.

Conditional Mutual Information: I(X;Y|Z) = H(X|Z) − H(X|Y,Z)

4. Central Limit Theorem & Normal Distribution HIGH

Central Limit Theorem (CLT)

If X₁, X₂, ..., Xₙ are i.i.d. random variables with mean μ and variance σ², then for large n:

The sample mean X̄ is approximately Normal: X̄ ~ N(μ, σ²/n)

The sum Sₙ is approximately Normal: Sₙ ~ N(nμ, nσ²)

Rule of thumb: n ≥ 30 is "large enough."

Law of Large Numbers (LLN)

As n → ∞, the sample mean X̄ₙ converges to the population mean μ. In other words, with enough data, the sample average will be very close to the true average.

Weak LLN: For any ε > 0, P(|X̄ₙ − μ| > ε) → 0 as n → ∞

CLT tells you the shape of the distribution (Normal); LLN tells you the sample mean converges to the true mean.

STANDARDIZATION (Z-SCORE) For individual X: Z = (X − μ) / σ For sample mean X̄: Z = (X̄ − μ) / (σ/√n) For sum Sₙ: Z = (Sₙ − nμ) / (σ√n) NORMAL APPROXIMATION TO BINOMIAL X ~ Binomial(n, p) μ = np, σ = √(np(1−p)) Z = (X − np) / √(np(1−p)) With continuity correction: P(X < k) ≈ P(Z < (k−0.5−np)/√(np(1−p))) INVERSE Z (Finding values from percentiles) x = μ + z · σ where z is looked up from the Z-table for the desired percentile

5. Maximum Likelihood Estimation MEDIUM

What is it?

MLE finds the parameter value θ that makes the observed data most probable. We write the likelihood function, take its log, differentiate, set to 0, and solve.

MLE PROCEDURE 1. Write the likelihood: L(θ) = Π P(xᵢ | θ) (product of all data probabilities) 2. Take the log-likelihood: ℓ(θ) = ln L(θ) = Σ ln P(xᵢ | θ) 3. Differentiate: dℓ/dθ = 0 4. Solve for θ̂ (the MLE) 5. Verify it's a maximum (second derivative < 0) COMMON MLEs Normal(μ, σ²): μ̂ = x̄ = (1/n)Σxᵢ, σ̂² = (1/n)Σ(xᵢ−x̄)² Bernoulli(p): p̂ = x̄ = (number of successes)/n Poisson(λ): λ̂ = x̄ Exponential(λ): λ̂ = 1/x̄ PROPERTIES OF MLE • Consistent: θ̂ → θ as n → ∞ • Asymptotically normal and efficient • Invariant: if θ̂ is MLE of θ, then g(θ̂) is MLE of g(θ)
PRACTICE — MLE for Normal Distribution

Problem: Data: {3, 5, 7, 9, 11}. Assuming Normal(μ, σ²), find MLE for μ and σ².

μ̂ = x̄ = (3+5+7+9+11)/5 = 35/5 = 7
σ̂² = (1/5)[(3−7)²+(5−7)²+(7−7)²+(9−7)²+(11−7)²]
= (1/5)[16+4+0+4+16] = 40/5 = μ̂ = 7, σ̂² = 8
Note: MLE uses 1/n, NOT 1/(n−1). The sample variance S² uses 1/(n−1).
PRACTICE — MLE for Exponential

Problem: Lifetimes (in hours): {2.1, 3.5, 1.8, 4.2, 2.9}. Find MLE for λ if X ~ Exp(λ).

x̄ = (2.1+3.5+1.8+4.2+2.9)/5 = 14.5/5 = 2.9
λ̂ = 1/x̄ = 1/2.9 = 0.3448

6. Bayesian Networks MEDIUM

What is it?

A Bayesian Network (BN) is a directed acyclic graph (DAG) where nodes represent random variables and edges represent probabilistic dependencies. Each node has a conditional probability table (CPT). BNs allow us to compute joint and conditional probabilities efficiently using the chain rule.

JOINT PROBABILITY FROM A BAYESIAN NETWORK P(X₁, X₂, ..., Xₙ) = Π P(Xᵢ | Parents(Xᵢ)) KEY CONCEPTS • Parent node: directly influences child • Root node: no parents → uses marginal probability P(X) • Conditional independence: X ⊥ Y | Z if knowing Z makes X and Y independent • d-separation: determines conditional independence in the graph MARKOV BLANKET The Markov Blanket of node X = {Parents(X)} ∪ {Children(X)} ∪ {Other parents of Children(X)} → Given its Markov blanket, X is conditionally independent of ALL other nodes LOCAL MARKOV PROPERTY Each node is conditionally independent of its non-descendants given its parents: X ⊥ NonDescendants(X) | Parents(X) INFERENCE To find P(A | evidence): P(A | B=b) = P(A, B=b) / P(B=b) Use marginalization: P(B=b) = Σ_A P(A, B=b)
PRACTICE — Bayesian Network Computation

Problem: A BN has: Rain → Sprinkler, Rain → WetGrass, Sprinkler → WetGrass.

Given: P(R=T)=0.2, P(S=T|R=T)=0.01, P(S=T|R=F)=0.4, P(W=T|S=T,R=T)=0.99, P(W=T|S=T,R=F)=0.90, P(W=T|S=F,R=T)=0.80, P(W=T|S=F,R=F)=0.0

Find P(Rain=T | WetGrass=T).

Use Bayes: P(R=T|W=T) = P(W=T|R=T)·P(R=T) / P(W=T)
P(W=T|R=T): Marginalize over S:
= P(W=T|S=T,R=T)·P(S=T|R=T) + P(W=T|S=F,R=T)·P(S=F|R=T)
= 0.99×0.01 + 0.80×0.99 = 0.0099 + 0.792 = 0.8019
P(W=T|R=F): = 0.90×0.4 + 0.0×0.6 = 0.36
P(W=T) = P(W=T|R=T)·P(R=T) + P(W=T|R=F)·P(R=F)
= 0.8019×0.2 + 0.36×0.8 = 0.16038 + 0.288 = 0.44838
P(R=T|W=T) = 0.16038/0.44838 = 0.3577
PRACTICE — Alarm Network (from Session 22)

Problem: Classic BN: Burglary(B) → Alarm(A) ← Earthquake(E), Alarm → JohnCalls(J), Alarm → MaryCalls(M).

Given: P(B)=0.001, P(E)=0.002, P(A|B,E)=0.95, P(A|B,¬E)=0.94, P(A|¬B,E)=0.29, P(A|¬B,¬E)=0.001, P(J|A)=0.90, P(J|¬A)=0.05, P(M|A)=0.70, P(M|¬A)=0.01

Find P(B|J=T, M=T).

Joint factorization: P(B,E,A,J,M) = P(B)·P(E)·P(A|B,E)·P(J|A)·P(M|A)
By Bayes: P(B|J,M) = P(J,M|B)·P(B) / P(J,M)
Key insight: Must marginalize over E and A. This is the standard "explain away" example — if the alarm went off (J and M called), it's more likely to be burglary, but if we also know there was an earthquake, the probability of burglary goes down (explaining away).
Markov blanket of B: {A, E} — B is independent of J,M given A.
PRACTICE — BN: Joint Probability Computation

Problem: Given a simple chain: A → B → C. P(A=1)=0.3, P(B=1|A=1)=0.8, P(B=1|A=0)=0.2, P(C=1|B=1)=0.9, P(C=1|B=0)=0.1. Find P(A=1, B=1, C=0).

Chain rule: P(A,B,C) = P(A)·P(B|A)·P(C|B)
P(A=1, B=1, C=0) = P(A=1) × P(B=1|A=1) × P(C=0|B=1)
= 0.3 × 0.8 × (1−0.9) = 0.3 × 0.8 × 0.1 = 0.024

7. Correlation & Linear Regression MEDIUM

What is it?

Linear regression fits a line ŷ = b₀ + b₁x to data points. Correlation (r) measures the strength and direction of the linear relationship between two variables.

ρ (rho) = population correlation — true but unknown. r = sample correlation — computed from data. r estimates ρ.

CORRELATION COEFFICIENT (Pearson's r) r = [nΣxᵢyᵢ − (Σxᵢ)(Σyᵢ)] / √{[nΣxᵢ² − (Σxᵢ)²][nΣyᵢ² − (Σyᵢ)²]} Also: r = Sxy / (Sx · Sy) where Sxy = Σ(xᵢ−x̄)(yᵢ−ȳ)/(n−1) Properties: −1 ≤ r ≤ 1 r = 1: perfect positive linear r = −1: perfect negative linear r = 0: no linear relationship LINEAR REGRESSION COEFFICIENTS b₁ (slope) = [nΣxᵢyᵢ − (Σxᵢ)(Σyᵢ)] / [nΣxᵢ² − (Σxᵢ)²] Also: b₁ = r · (Sy/Sx) b₀ (intercept) = ȳ − b₁·x̄ Regression line: ŷ = b₀ + b₁·x COEFFICIENT OF DETERMINATION R² = r² Interpretation: proportion of variance in Y explained by X RESIDUAL eᵢ = yᵢ − ŷᵢ (actual minus predicted) SUM OF SQUARES SST = Σ(yᵢ − ȳ)² (Total) SSR = Σ(ŷᵢ − ȳ)² (Regression/Explained) SSE = Σ(yᵢ − ŷᵢ)² (Error/Residual) SST = SSR + SSE R² = SSR/SST = 1 − SSE/SST
PRACTICE — Linear Regression

Problem: Data: x = {1, 2, 3, 4, 5}, y = {2, 4, 5, 4, 5}. Find the regression line.

Compute sums: n=5, Σx=15, Σy=20, Σxy=67, Σx²=55
x̄=3, ȳ=4
b₁ = (5×67 − 15×20)/(5×55 − 15²) = (335−300)/(275−225) = 35/50 = 0.7
b₀ = 4 − 0.7×3 = 4 − 2.1 = 1.9
Regression line: ŷ = 1.9 + 0.7x
PRACTICE — Correlation Interpretation (from Session 23)

Problem: An e-commerce study finds r = 0.98 between ad spending (x) and revenue (y). What does this mean? If Sx = 200, Sy = 5000, find b₁.

r = 0.98: Very strong positive linear relationship. As ad spending increases, revenue increases almost perfectly linearly.
R² = 0.98² = 0.9604: 96.04% of the variance in revenue is explained by ad spending.
Slope shortcut: b₁ = r × (Sy/Sx) = 0.98 × (5000/200) = 0.98 × 25 = 24.5
Interpretation: For every $1 increase in ad spending, revenue increases by approximately $24.50.
⚠️ Correlation ≠ Causation! High r only means a linear association exists, not that x causes y. Also, r only captures linear relationships — two variables could have a strong nonlinear relationship with r ≈ 0.

8. Statistical Inference Foundations SUPPORTING

Key Definitions

Population: The entire group we want to study.

Sample: A subset of the population we actually observe.

Parameter: A number describing the population (μ, σ, p). UNKNOWN.

Statistic: A number computed from the sample (x̄, s, p̂). KNOWN.

Point Estimator: A single value estimate for a parameter (e.g., x̄ for μ).

Unbiased Estimator: E[θ̂] = θ (on average, hits the true value).

Bias: B(θ̂) = E[θ̂] − θ

Mean Squared Error: MSE(θ̂) = Var(θ̂) + [Bias(θ̂)]²

If unbiased (Bias=0), then MSE = Var. The MLE σ̂² = (1/n)Σ(xᵢ−x̄)² is biased; the sample variance S² = (1/(n−1))Σ(xᵢ−x̄)² is unbiased.

Frequentist vs. Bayesian

Frequentist: Parameters are fixed but unknown constants. Probability = long-run frequency. Uses MLE, confidence intervals.

Bayesian: Parameters are random variables with prior distributions. Updates beliefs using Bayes' theorem. Uses posterior distributions, credible intervals.

Order Statistics

If X₁, ..., Xₙ are i.i.d. with CDF F(x) and PDF f(x), the k-th order statistic X₍ₖ₎ is the k-th smallest value.

PDF of X₍ₖ₎: f₍ₖ₎(x) = [n! / ((k−1)!(n−k)!)] · [F(x)]^(k−1) · [1−F(x)]^(n−k) · f(x)

Special cases: X₍₁₎ = min, X₍ₙ₎ = max

PDF of minimum: f₍₁₎(x) = n·[1−F(x)]^(n−1)·f(x)
PDF of maximum: f₍ₙ₎(x) = n·[F(x)]^(n−1)·f(x)

SAMPLE STATISTICS Sample mean: x̄ = (1/n) Σxᵢ Sample variance: S² = (1/(n−1)) Σ(xᵢ − x̄)² [unbiased] = (1/(n−1))(Σxᵢ² − nx̄²) Sample std dev: S = √(S²) PROPERTIES E[X̄] = μ (unbiased for population mean) Var(X̄) = σ²/n E[S²] = σ² (unbiased for population variance)

Question 1 — Information Theory (20 points)

A communication channel transmits symbols A, B, C with probabilities P(A)=0.5, P(B)=0.3, P(C)=0.2.

(a) Find the entropy H of this source. (7 pts)

(b) Find the information content of receiving symbol C. (3 pts)

(c) A second source transmits the same symbols with equal probability. Which source has higher entropy? Explain. (5 pts)

(d) Convert your answer from (a) to nats. (5 pts)

Solution — Question 1
(a) H = −[0.5·log₂(0.5) + 0.3·log₂(0.3) + 0.2·log₂(0.2)]
= −[0.5(−1) + 0.3(−1.7370) + 0.2(−2.3219)]
= −[−0.5 − 0.5211 − 0.4644] = −(−1.4855) = 1.4855 bits
(b) I(C) = −log₂(0.2) = log₂(5) = 2.3219 bits
(c) Equal probability source: H = log₂(3) = 1.585 bits. The equal-probability source has HIGHER entropy because entropy is maximized when all outcomes are equally likely (maximum uncertainty).
(d) H_nats = 1.4855 × ln(2) = 1.4855 × 0.6931 = 1.0296 nats

Question 2 — CLT / Normal Distribution (20 points)

The download speed of an internet service has mean μ=50 Mbps and σ=8 Mbps.

(a) For a sample of n=64 users, find the probability that the average download speed is less than 48 Mbps. (10 pts)

(b) Find the download speed below which the slowest 10% of individual users fall. (10 pts)

Solution — Question 2

Z = (48 − 50)/1.0 = −2.0
P(X̄ < 48) = P(Z < −2.0) = 0.0228
(b) Need P(X < x) = 0.10 → z = −1.2816
x = 50 + (−1.2816)(8) = 50 − 10.25 = 39.75 Mbps

Question 3 — Confidence Interval (15 points)

A factory produces bolts with unknown mean length. A sample of n=25 bolts gives x̄=10.2 cm and s=0.5 cm. Assuming normal population:

(a) Find the 95% confidence interval using the t-distribution. (10 pts)

(b) How would the interval change if n=100 instead? (5 pts)

Solution — Question 3
(a) df = 24, t₀.₀₂₅,₂₄ ≈ 2.064 (from t-table)
Margin of error = 2.064 × 0.5/√25 = 2.064 × 0.1 = 0.2064
CI = [10.2 − 0.2064, 10.2 + 0.2064] = [9.994, 10.406]
(b) With n=100, we can use z instead of t (large n). z₀.₀₂₅ = 1.96
ME = 1.96 × 0.5/√100 = 1.96 × 0.05 = 0.098
CI = [10.102, 10.298] — Much narrower! Larger n → more precise.

Question 4 — Z-Test (15 points)

A manufacturer claims average battery life is μ₀=500 hours with known σ=30 hours. A consumer group tests n=36 batteries and finds x̄=490 hours. At α=0.05, is the battery life less than claimed?

Solution — Question 4
Hypotheses: H₀: μ = 500, H₁: μ < 500 (LEFT-tailed)
z = (490 − 500)/(30/√36) = −10/5 = −2.0
Critical value (left-tailed, α=0.05): z₀.₀₅ = −1.645
|z| = 2.0 > 1.645, and p = P(Z < −2.0) = 0.0228 < 0.05
Conclusion: REJECT H₀. There is significant evidence that battery life is less than 500 hours.
